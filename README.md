Wine Quality Dashboard | Power BI Project

Overview

This Power BI dashboard analyzes red wine quality based on key chemical properties such as alcohol content, pH, density, and sulphates. The goal is to identify factors that influence wine quality and provide clear insights through interactive visualizations.

Key Features

- Wine Quality Distribution
- Alcohol vs Quality Analysis
- Sulphates vs Quality Analysis
- Quality Category Segmentation
- Interactive Filtering
- KPI Summary Dashboard

Dashboard Highlights

- Total Wines: 1,599
- Average Alcohol: 10.42
- Average Quality: 5.64

Tools & Technologies

- Power BI Desktop
- DAX
- Data Visualization
- Business Intelligence
